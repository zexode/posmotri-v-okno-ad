# Посмотри в окно

Проектная работа второго спринта курса «Фронтенд-разработчик» Яндекс
Практикума. Страница показывает короткие видео городских видов и позволяет
искать их по городу и времени суток.

## Возможности

- загрузка видео и карточек с сервера Практикума;
- поиск по названию города и времени суток;
- переключение основного видео нажатием на карточку;
- загрузка следующих карточек;
- состояния загрузки и сообщения об ошибках;
- адаптивная вёрстка и управление с клавиатуры.

## Запуск

Проект не требует сборки. Запустите в корне репозитория локальный сервер:

```bash
python3 -m http.server 8000
```

Откройте в браузере <http://localhost:8000>.

## Проверки

GitHub Actions запускает тесты Яндекс Практикума при отправке изменений в
репозиторий. Результат доступен во вкладке **Actions**.
